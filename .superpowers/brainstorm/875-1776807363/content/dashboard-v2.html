¿Qué cambió vs antes?

  • Sin emojis: todos los iconos ahora son SVG limpios (Lucide Icons — el mismo pack que usan las apps premium)
  • Ticker arriba: cotizaciones en vivo siempre visibles (Blue, MEP, CCL, Oficial, USDT, BTC)

  • Tipografía Inter: sans-serif moderna, igual que Linear / Vercel / Stripe
  • Componentes de 21st.dev: usaremos cards, charts y sidebar de ahí para acelerar
